### Forks and modified versions

You are free to create forks and modified versions of AIOS.

However, modified or third-party versions are **not official AIOS
releases** unless explicitly published or endorsed by the official project.

Forks and derivative projects should use their own project name, logo, and
branding so that users can distinguish them from the official AIOS
project.

A third-party project may state that it is based on or derived from
AIOS when that is factually accurate, but it must not imply that it is
the official project or that it is maintained or endorsed by the original
authors.
